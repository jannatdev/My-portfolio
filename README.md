# 🚀 Project Name

### My Portfolio


# 📝Description
A modern, responsive, and professional portfolio website built with Next.js to showcase my skills, projects, and experience as a Full-Stack Web Developer. The website highlights my technical expertise, featured projects, and provides an easy way for potential clients, recruiters, and collaborators to connect with me.


# 🛠️ Technologies Used

## Frontend:
- Next.js
- React
- JavaScript (ES6+)
- TypeScript
- Tailwind CSS
- HTML5

## Backend:
 - Node.js
 - Express.js
 - MongoDB


# ⚙️Tools & Services

- Git & GitHub
 - Vercel
 - Email Integration
